# Notes for whoever runs this website

Eight files. **If you have just taken over the site, start with
[ORIENTATION.md](ORIENTATION.md)** and ignore the rest of this table until you
have read it.

| If you want to | Read |
|---|---|
| Get your bearings, having just inherited this | **[ORIENTATION.md](ORIENTATION.md)** |
| Change something on the site: an officer, the gear list, a photo, a link | the main [README](../README.md), not this folder |
| Get an account and a key so you can deploy at all, or hand access over when you leave | **[ACCESS.md](ACCESS.md)** |
| Put the site onto the Caltech server, or fix a deploy that went wrong | **[DEPLOY.md](DEPLOY.md)** |
| Know what machine the site runs on, where the files go, what the passwords are for | **[SERVERS.md](SERVERS.md)** |
| See what happened last time somebody deployed | **[DEPLOY-LOG.md](DEPLOY-LOG.md)** |
| Understand why the site is hosted the way it is, or argue for changing it | **[HOSTING.md](HOSTING.md)** |
| Write anything that appears on the site | **[WRITING.md](WRITING.md)** |

None of these are needed for ordinary club business. Adding a trip means adding
a Google Calendar event, and nothing in this folder is involved.

**The two files that go stale first are `SERVERS.md` and `DEPLOY-LOG.md`.**
Both are written as records with dates on them, so when a fact is wrong it is
visibly old rather than quietly wrong. If you look something up and the file
disagrees with reality, fix the file. That takes a minute and saves the next
person an afternoon.
